#### 1. Rodar a aplicação (interface gráfica):

    ./project.sh run

  │ Se quiser rodar apenas os testes:
  │
  │   ./project.sh test
  ──────

#### 2. Atualizar e recompilar o executável (.EXE):

    ./project.sh update

  (Executa a suíte de testes e, se todos passarem, recompila o executável em dist/CDB_Simulator.exe)
  ──────

#### 3. Rodar apenas os testes:

    ./project.sh test
  ──────

> Nota: O projeto agora é exclusivamente para desktop (.exe). Não há mais suporte a CLI/terminal nem scripts de preview/publish.
> Os dados financeiros ficam criptografados em ~/.cdb_simulator/ e não são apagados ao atualizar o .exe.
